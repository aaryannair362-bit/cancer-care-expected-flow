# PC4.0 Handoff Matrix

| Trigger | Destination |
|---|---|
| Registration / check-in | Intake |
| Intake complete | Medical Oncology / destination clinic |
| Investigation result final | Ordering clinician Results Inbox |
| MDT signed recommendation | Treatment Plan owner |
| Treatment Plan signed | Systemic order / RT / Surgery owner |
| Systemic order signed | Oncology Pharmacy |
| Pharmacy product released | Day Care / Infusion Nurse |
| Administration complete | Medical Oncology cycle review |
| RT prescription / plan released | Radiation delivery team |
| Surgery performed | Pathology |
| Final pathology | Surgical Oncology + treating team |
| Confirmed response | Treating clinician / MDT as indicated |
| Treatment completion | Surveillance / Navigator |
| Surveillance recurrence suspicion | Treating oncology specialty / MDT |
